# 검사기 fixture

`assets/deck.html`의 자기검사기를 시험한다. 껍데기는 복사하지 않고 `deck.html`에서
끌어오므로 검사기가 갈라지지 않는다.

## 돌리는 법

```bash
cd skills/learning-deck-builder
node tests/build.mjs broken
```

`tests/out/broken.html`을 브라우저로 열고 콘솔에서:

```js
__deckCheck()
```

## 대조군

| 파일 | 기대 |
|---|---|
| `tests/out/broken.html` | 아래 목록이 전부 잡힌다 (14건) |
| `assets/deck.html` (그대로 열기) | 위반 0건 |

## broken.html 에서 나와야 하는 위반

아래는 다음 명령으로 실제로 받아 적은 출력이다. 손으로 짓지 않았다.

```bash
cd skills/learning-deck-builder
node tests/build.mjs broken
python3 -m http.server 8791 &   # file:// 는 막혀 있어서 필요
# 브라우저에서 http://localhost:8791/tests/out/broken.html 을 열고
window.__deckCheck()
window.__deckStats
# 콘솔 로그도 같이 확인
```

`__deckCheck()`가 돌려준 배열은 총 **14건**이다.

| 게이트 | 메시지 (앞부분, 실측) |
|---|---|
| data-goal 없음 | `3번(goal): 설명 장인데 data-goal이 없다` |
| 코드 해설 문단 없음 | `5번(example): 코드에 해설 문단이 없다` |
| 완결문장 제목 | `6번(precise): 제목이 주제어다` |
| 비유 매핑표 없음 | `8번(intro): 비유를 썼다고 표시했는데 매핑표(.map)가 없다` |
| 비유 "깨지는 지점" 없음 | `8번(intro): 비유를 썼다고 표시했는데 "깨지는 지점"(.caveat)이 없다` |
| 모르는 data-kind | `9번(myth): data-kind="myth"는 모르는 값이다` |
| 붙일 곳이 아닌 data-goal | `10번(closing): data-goal="g1"을 붙일 장이 아니다` |
| 학습목표 선언 수 | `학습목표 선언 1개 (하한 2)` |
| 학습목표 어미 | `학습목표 1번이 "할 수 있게 되는 것"이 아니다` |
| 열기 장 산문 하한 | `열기 장 산문 10자 (하한 400)` |
| 미아 목표값 | `7번(intro): data-goal="g9"가 열기 장에 선언되지 않았다` |
| 3박자 순서 | `학습목표 "g1": "실제 예시" 장이 "엄밀한 설명" 장보다 먼저 나온다` |
| 목표별 퀴즈 | `학습목표 "g1": 확인 퀴즈가 없다` |
| 목표별 산문 하한 | `학습목표 "g1": 산문 18자 (하한 1200)` |

주: "비유 무결성" 게이트는 매핑표와 "깨지는 지점"을 따로 검사해서 위반도 따로 두 줄
나온다. 이 표에서도 두 줄로 나눠 적었다 — 합치면 실제 배열과 줄 수가 안 맞는다.

## 학습 시간과 학습목표 개수 안내는 위반이 아니다

`__deckStats`가 돌려준 값(실측):

```json
{ "minutes": 1, "prose": 40, "codeLines": 1, "figures": 0, "quizzes": 1 }
```

콘솔에는 다음 세 줄이 뜬다(실측, 요약 없이 그대로):

```
[learning-deck-builder] 슬라이드 10장 · 추정 학습 시간 약 1분 (산문 40자, 코드 1줄, 그림 0개, 퀴즈 1개)
[learning-deck-builder] 참고 — 추정 학습 시간 1분. 목표는 60~120분이다. 위반은 아니지만 커리큘럼의 챕터 분할을 다시 봐라
[learning-deck-builder] 참고 — 학습목표 1개. 챕터 하나는 4~6개다. 위반은 아니지만 커리큘럼의 챕터 분할을 다시 봐라
```

세 줄 다 `console.info`다. `console.warn`은 위반 목록에만 쓴다 — 콘솔만 보고 안내와
위반을 가를 수 있게 해 뒀다.

이 세 줄은 **콘솔에만** 나온다. `window.__deckCheck()`가 돌려주는 배열에는 학습 시간도
학습목표 개수도 없다 — 위반이 아니라 별도의 안내이기 때문이다.

안내가 뜨는 기준과 메시지에 적힌 숫자는 서로 다른 두 구간이다. 두 안내는
`assets/deck.html` 맨 끝, `__deckCheck()`를 부른 뒤의 콘솔 블록에 있다.

- 학습 시간 안내가 **뜨는 기준(트리거)**은 추정치가 **50~140분** 범위를 벗어날 때다.
- 메시지 문구에 적힌 **60~120분**은 트리거가 아니라 **목표(target)** 구간이다 — 트리거
  구간보다 좁다.
- 두 구간이 다른 이유: 추정치 자체가 대략적인 근사값이라, 안내를 띄우는 기준은
  일부러 목표 구간보다 넓게 잡아뒀다. 그 결과 예를 들어 55분짜리 챕터는 목표(60~120분)
  에서는 벗어나 있지만 50~140분 트리거 안에는 들어가므로 **안내가 뜨지 않는다** —
  조용히 넘어간다.
- 학습목표 개수 안내는 선언된 목표가 **4~6개**가 아닐 때 뜬다. 게이트 하한은 2개라
  목표 2~3개짜리 챕터는 위반 없이 통과하는데, 그 상태를 알려 주는 것이 이 안내다.
- broken.html은 일부러 아주 작은 fixture다. 1분 추정치가 두 구간(50~140분, 60~120분)을
  전부 벗어나고 목표도 1개뿐이라, 두 안내가 다 뜨는 것이 정상이다. 안 뜨면 오히려
  그게 이상한 것이다.
